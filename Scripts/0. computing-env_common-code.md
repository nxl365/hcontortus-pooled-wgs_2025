# Computing environment

Bash scripts were run as SLURM jobs on Dardel, a high-performance computing system provided through the National Academic Infrastructure for Supercomputing in Sweden (NAISS) and hosted at PDC, KTH Royal Institute of Technology, Sweden.

Some downstream plotting and analyses using R and Python were performed locally.



# Common commands for running and managing HPC jobs

```bash

# Run the script directly in the foreground without SLURM
bash <filename.sh>


#### SLURM batch job
# Submit a SLURM batch job
sbatch <filename.sh>

# Submit a dependent job that starts only after the previous job finishes successfully
sbatch --dependency=afterok:<previous_jobID> <your_script.sh>


# cancel your job from queue
scancel <jobid>   # a series of number when you submit job
scancel -u <your_username> #Cancel all your jobs

# check your job in the queue 
squeue -u <username>   
squeue -u nancyliu


#To get further information about your jobs:
scontrol show job <jobid>

#To get detailed status information of a running job/step:
sstat --jobs=<your_job-id>

```
