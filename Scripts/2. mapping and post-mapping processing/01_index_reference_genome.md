## Reference genome indexing


### Tools
* bwa 
* samtool 
* picard 

Before read mapping, the reference genome needs to be indexed.
BWA index files are required for read alignment with bwa mem. The .fai index generated by SAMtools and the .dict sequence dictionary generated by Picard are commonly required by downstream tools such as SAMtools, Picard, and GATK.


## SLURM bash script
Create the bash script:

```bash
module load nano
nano 4_index_refer_genome.sh
```

Script content:
```bash
#!/bin/bash -l
#SBATCH -A naiss2025-22-***
#SBATCH -n 3                 # 3 tasks
#SBATCH --cpus-per-task=1    # each task use 1 CPU core
#SBATCH -t 01:00:00
#SBATCH -p shared
#SBATCH -J index
#SBATCH --mail-type=All
#SBATCH --mail-user=nanxing.liu@slu.se   

module load bwa/0.7.18 samtools/1.20 picard/3.3.0

refer_genome='.../raw_data/Hc_reference_genome/haemonchus_contortus.PRJEB506.WBPS19.genomic.fa'
refer_file='.../raw_data/Hc_reference_genome/'


# Generate BWA index files: 
# No multi-threading support, only use 1 thread anyway
# put output in the same folder of reference automatically
# why ---for bwa mapping
bwa index $refer_genome

# Generate .fai index of refer genome using samtools, 
# put output in the same folder of reference automatically
# No multi-threading support, only use 1 thread anyway
# why --- for samtool, GATK...if needed
samtools faidx $refer_genome

# Generate Picard sequence dictionary/index .dict,
# need to set that put output in same folder of reference
# No multi-threading support,  only use 1 thread 
# why --- for GATK... if needed
java -jar $PICARD CreateSequenceDictionary R=$refer_genome O="$refer_file/haemonchus_contortus.PRJEB506.WBPS19.genomic.dict"



```


### Submit the SLURM job

```bash
sbatch 4_index_refer_genome.sh
```


### Running time:
Approximately 3 minutes.



### Input data

The input file was the decompressed *H. contortus* reference genome in .fa format:
```text
haemonchus_contortus.PRJEB506.WBPS19.genomic.fa
```


### Output

Keep the index files in the same directory as the reference genome. 
Here, three types of index files were generated: BWA, SAMtools `.fai`, and Picard `.dict`.

